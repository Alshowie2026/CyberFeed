## Implementation Strategy

### MVP First

1. أكمل Setup وFoundational.
2. نفّذ US1 واعرض التسجيل والفرادة والحفظ كزيادة أولى.
3. نفّذ US2 لإكمال MVP قابل للاستخدام: إنشاء حساب ثم تسجيل الدخول والخروج. يلزم ذلك لأن الاختبار المستقل في المواصفات يتضمن الدخول بعد الإنشاء.
4. نفّذ US3 قبل إصدار ميزة المصادقة الكاملة؛ بدونها يظل مسار النشر القديم غير محمي.
5. نفّذ فحوص الجودة والأداء والتجربة البشرية. غياب مشاركين أو جهاز القياس المستهدف يُسجّل كتحقق غير مكتمل ولا يُختلق له نجاح.

### Incremental Delivery

كل مرحلة تنتهي بإثباتها وتقرير نتائجها دون الإضرار بالمنشورات السابقة. لا تضف إعادة تعيين كلمات مرور أو أدوار إدارة أو تغيير أسماء أو مصادقة خارجية؛ كلها خارج المواصفات. يُنشأ auth.json وقت التشغيل في مجلد البيانات المحدد ولا يحتوي المستودع حسابات حقيقية أو كلمات مرور نموذجية محفوظة.
